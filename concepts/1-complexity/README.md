# Introduction to Time and Space Complexity

## Time Complexity

Time complexity is a measure of the amount of time an algorithm takes to complete as a function of the input size. It helps evaluate how efficiently an algorithm scales.

### Common Notations:

1. **O(1):** Constant time - the algorithm runs in the same time regardless of input size.
2. **O(log n):** Logarithmic time - grows slower as input size increases (e.g., binary search).
3. **O(n):** Linear time - grows directly proportional to the input size.
4. **O(n^2):** Quadratic time - grows with the square of the input size (e.g., nested loops).
5. **O(2^n):** Exponential time - doubles with each additional input size.

## Space Complexity

Space complexity measures the amount of memory an algorithm uses as a function of the input size. It considers:

1. Variables used.
2. Data structures employed.
3. Function call stack.
