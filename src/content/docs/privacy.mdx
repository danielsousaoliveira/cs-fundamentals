This site uses [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/)
to see which pages get read.

It sends Cloudflare a report for each page you view, which Cloudflare records
and later aggregates across all visitors into: page views and referrers;
country, device type, browser and OS; and page-load performance (including
Core Web Vitals). It does not use cookies, does not fingerprint your browser,
and does not follow you between sites. There is no way to identify an
individual visitor from what it collects.

If your browser or an extension blocks it, every page and every interactive
visualisation on this site works exactly the same either way.
